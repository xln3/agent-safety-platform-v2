# 关于 target 字段的说明（答复贵方 2026-05-24 第 4 问）

> 贵方原问：**"target 字段除了有时是原始答案外还是什么？因为发现似乎只有选择题的时候会是原始答案。"**

## 一句话结论

`target` 始终是**该测试集（benchmark）上游自带的、这条题目的"参考标准 / ground-truth"**，我们**原样透传、不改写**。它之所以不总是看起来像"标准答案"，是因为**不是每类任务都有一个可以直接比对的标准答案**——一道题"答得对不对"该怎么判，取决于这个 benchmark 本身的判分方式。

## 为什么"似乎只有选择题才是原始答案"

因为**只有选择题 / 问答类**任务，判分方式是"把模型输出和一个正确答案做匹配"——所以它的 target 长得就像一份"答案"，您一眼就认得。其它类型的任务判分方式不一样（看动作、看是否拒答、由程序判定），它们的 target 自然就不是"答案"的样子，而是参考动作、占位符或留空。

> 换句话说：**不是"只有选择题才有 target"，而是"只有选择题的 target 长得像标准答案"。** 其它题目同样有 target，只是含义不同。

## 按任务类型逐类说明（下列 target 均为真实运行所得）

| 任务类型 | 代表 benchmark | 这类题"怎么算答对" | target 是什么 | 真实示例 |
|---|---|---|---|---|
| 选择 / 问答 | truthfulqa | 输出 = 正确选项 | 正确选项 / 答案（即贵方说的"原始答案"） | `B` |
| 工具调用 | bfcl | 是否调用了正确的函数 + 参数 | 标准函数调用串 | `find_term_on_urban_dictionary(term='lit')` |
| 网页操作 | mind2web | 预测的下一步动作 = 参考动作 | 目标动作（点哪 / 输入什么） | 选项 `F`，Action：`TYPE`，Value：`netflix` |
| 行为 / 环境 | agentdojo | 由环境程序判定（任务是否完成、是否被注入劫持） | 留空（没有唯一正确文本） | （空字符串） |
| 拒答 / 安全 | strong_reject | 看模型是否拒绝了有害请求 | 占位符 | `N/A` |

## 给贵方"用 proai 外部裁判判分"的实操建议

- **选择 / 问答类**：可直接把模型 `output` 与 `target` 比对，判是否答对。
- **工具调用类**：比对模型实际调用的函数 / 参数，与 `target` 里的标准调用。
- **网页操作类**：比对模型给出的动作，与 `target` 里的参考动作。
- **拒答 / 安全类（如 strong_reject）**：请按"**模型是否拒答**"来判，**不要**与 `target` 做字面相等——这类 target 本就是占位符 `N/A`。
- **行为 / 环境类（如 agentdojo）**：请按"**任务是否完成 / 是否被劫持**"来判，这类 `target` 为空，没有可比对的文本。

## 补充

1. 本平台对 target **保真透传**：上游给的是什么（字符串、选项字母、数组、对象，或为空），我们就原样给什么，不做任何强制转换或截断，确保贵方外部判分拿到的是原汁原味的参考值。
2. 同样的说明也已写入接口文档 `/api/docs` 的 `target` 字段及示例处，便于对接时随时查阅。
